# The data-quality frontier

The write-up grounding milestone `05-data-frontier`'s corpus choice, in the
format this directory's README prescribes: what problem each technique
solves, what it costs, and where it breaks down at this repo's model sizes.

## The problem

Below ~1B parameters, benchmark capability is bottlenecked by data quality
more than by architecture or parameter count. Milestones 02–04 demonstrated
the failure mode locally: models trained on TinyStories reach fluent
generation while HellaSwag/ARC/MMLU stay at chance, because the corpus
contains no factual, physical, or academic signal — and no long-range
structure for attention research either. The literature says the biggest
single lever at small scale is refining what goes in, not adding parameters.

## Techniques

**phi — "Textbooks Are All You Need" (Gunasekar et al., 2023).**
- *Solves*: small models drowning in low-quality web text. phi-1 (1.3B)
  matched much larger models on code by training on filtered "textbook
  quality" data plus GPT-generated synthetic textbooks.
- *Costs*: a strong teacher model to generate/filter; risks benchmark
  contamination and narrow distribution (phi models are famously
  benchmark-strong / distribution-narrow).
- *Breaks down*: pure-synthetic corpora inherit the teacher's blind spots;
  diversity collapse is measurable below ~100M params where capacity can't
  even cover the synthetic distribution.

**FineWeb-Edu (HuggingFace, 2024).**
- *Solves*: web-scale data with textbook-ish quality, without a synthetic
  pipeline: an educational-quality classifier (trained on Llama-3-70B
  annotations) filters CommonCrawl down to ~1.3T high-value tokens.
- *Costs*: classifier bias (favors expository English prose; code and
  dialogue are underrepresented). Freely downloadable in plain parquet.
- *Breaks down*: little at our scale — it's the current default choice for
  small-model pretraining. The `sample-10BT` subset (~10B gpt2 tokens,
  14 shards) is sized perfectly for local work.

**Cosmopedia-v2 / SmolLM corpus (HuggingFace, 2024).**
- *Solves*: the phi recipe, open-sourced: ~28B tokens of synthetic
  textbooks/stories generated by Mixtral-8x7B. Used (with
  fineweb-edu-dedup, 220B tokens) to train SmolLM/SmolLM2-135M — the
  strongest published models at our exact size class.
- *Costs*: synthetic-data narrowness (see phi); best used as a minority
  blend component, which is how SmolLM used it.
- *Breaks down*: same diversity caveats as phi at very small scale.

**DCLM-baseline (2024).**
- *Solves*: same goal as FineWeb-Edu via a model-based quality classifier
  tuned on instruction-ish positives; often beats FineWeb-Edu on
  commonsense/reasoning benchmarks (at the cost of MMLU-style knowledge).
- *Status here*: the natural A/B alternative corpus — deferred; one refined
  corpus at a time keeps the experiment interpretable.

**python-edu (SmolLM corpus).** Excluded for logistics, not merit: the
parquet ships only metadata; actual code text requires per-blob Software
Heritage S3 pulls (hours on many cores). Revisit if code capability becomes
a target.

## What 05 does with this

`experiments/05-data-frontier/data.py` builds a **~1.78B-token pool**:
~84.5% FineWeb-Edu `sample-10BT` (2 shards) + ~15.5% Cosmopedia-v2
(1 shard), tokenized with tiktoken gpt2 — mirroring SmolLM's
majority-filtered-web / minority-synthetic blend at 1/300th the size.
Reference points this enables (published 0-shot): Cerebras-GPT-111M
(2.2B Pile tokens): HS 26.8 / PIQA 59.4; Pythia-160M (300B): 29.9 / 62.0;
OPT-125M (180B): 31.1 / 62.0; SmolLM2-135M (2T refined): 42.1 / 68.4.
The distance between Pythia-160M and SmolLM2-135M at near-identical size
IS the data-quality effect this milestone imports.
